# Retail Sales & Profitability Dashboard Using Excel

### Project Overview
This project focuses on cleaning raw retail transaction data and building an interactive executive dashboard using Microsoft Excel. The aim is to track monthly revenue trends, analyze regional and product-wise profitability, and provide actionable business insights for retail decision-making.

### Project Objectives
* Clean and standardize messy raw transactional data (handling missing quantities, inconsistent region formatting, and duplicate orders).
* Analyze net revenue, total cost, and profit margins across different regions and product lines.
* Utilize advanced Excel formulas (`SUMIF`, `SUMIFS`, `GETPIVOTDATA`) and PivotTables for dynamic summarization.
* Build an intuitive, interactive dashboard featuring KPI summary cards and slicers.
* Present key performance findings directly alongside visualizations to support business decision-making.

### Tools and Techniques
* **Tool:** Microsoft Excel
* **Techniques Used:**
  * Data cleaning and standardization (handling whitespace, duplicates, and missing values)
  * Excel functions (`SUMIF`, `SUMIFS`, `GETPIVOTDATA`, conditional logic)
  * PivotTables and Pivot Charts
  * Interactive data slicers for dynamic filtering
  * Data visualization and executive dashboard layout design

### Dataset Description
The project utilizes a multi-tab practice dataset (`Raw_data`, `Cleaned_data`, `Pivot_tables`, `Dashboard`) containing retail transaction records, including:
* Order ID & Order Date
* Customer ID & Product ID
* Region (North, South, East, West)
* Quantity, Unit Price, Unit Cost, and Discount Percentage
* Calculated fields: Net Revenue, Total Cost, Profit, and Profit Margin

### Key Learning Outcomes
Through this project, I developed practical experience in:
* Transforming messy, unformatted operational data into clean, structured datasets ready for analysis.
* Implementing robust lookup and conditional aggregation formulas in Excel.
* Designing user-friendly executive dashboards with integrated charts and slicers.
* Translating raw transaction figures into clear business insights (e.g., identifying top-performing regions and high-margin product lines).
